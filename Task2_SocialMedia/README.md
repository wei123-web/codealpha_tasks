# Task 2 - Social Media Platform

A full-stack mini social media app built for the CodeAlpha Full Stack Development Internship.

## Features
- User registration and login (JWT + bcrypt)
- Create posts, like, and comment
- Follow other users
- Trending feed sorted by likes

## Tech Stack
- Frontend: React (Vite)
- Backend: Node.js, Express.js
- Database: MySQL

## Setup
1. cd backend && npm install && node server.js
2. cd frontend && npm install && npm run dev
3. Import database.sql into MySQL Workbench
