# Task 1 - Simple E-commerce Store

A full-stack e-commerce web application built for the CodeAlpha Full Stack Development Internship.

## Tech Stack
- Frontend: React (Vite)
- Backend: Node.js, Express.js
- Database: MySQL

## Setup
1. cd backend && npm install && node server.js
2. cd frontend && npm install && npm run dev
3. Import database.sql into MySQL Workbench
